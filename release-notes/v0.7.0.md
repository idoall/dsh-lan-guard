<h3 id="cn-v0.7.0">📱 v0.7.0：在手机上看历史轮次，终于顺手了</h3>

兼容 DeepSeek Harness `0.2.1-alpha.1`。

- 修掉 iPhone 上按住刻度时卡片跑到屏幕外、字看不清的问题。
- 长按刻度后上下滑动，就能一路看每一轮在讲什么；松手停在哪一轮，就看哪一轮。
- 手指选中的刻度会变成一根蓝色长条，一眼看出现在指着第几轮。
- 不会再误触上传文件，也不会拖着拖着整页跟着动或刷新。
- 修掉重启后手机打开是白屏的问题。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。轮次浮轨默认关闭，在 **设置 → 局域网访问 → 连接与证书 → 手机端轮次导航** 里打开，刷新页面生效。

<h3 id="en-v0.7.0">📱 v0.7.0: browsing older turns on your phone finally feels right</h3>

Compatible with DeepSeek Harness `0.2.1-alpha.1`.

- Fixed the card jumping off screen on iPhone while holding a tick.
- Hold a tick and slide to skim every turn; release on the turn you want to read.
- The selected tick turns into a blue bar, so you can see where you are.
- No more accidental file upload, and no page dragging or refresh mid-gesture.
- Fixed the blank page phones sometimes got after a restart.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Restart dsh once. The rail is off by default: turn it on under **Settings → 局域网访问 → 连接与证书 → 手机端轮次导航**, then reload the page.
