<h3 id="cn-v0.4.1">📱 第一版手机滚动修复</h3>

兼容 DeepSeek Harness `0.1.7-rc.2`。

- 修手机上聊天区滑不动的问题：只在确实滑不动的页面上动手，正常页面完全不碰。
- 新增布局诊断：地址后加 ?lgdiag=1，出问题时能一眼看出页面布局状态。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。

<h3 id="en-v0.4.1">📱 The first mobile scroll fix</h3>

Compatible with DeepSeek Harness `0.1.7-rc.2`.

- Fixes conversations that would not scroll on a phone: it only acts on pages that really cannot scroll, and leaves healthy pages alone.
- Adds a layout report at ?lgdiag=1 so a broken page explains itself.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Restart dsh once.
