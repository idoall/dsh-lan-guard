<h3 id="cn-v0.7.5">🔌 v0.7.5：跟上 DSH 0.2.1-rc.2</h3>

兼容 DeepSeek Harness `0.2.1-rc.2`。

- 声明支持 DSH `0.2.1-rc.2`：插件代码一行没动。
- 在 `0.2.1-rc.2` 上确认过：手机端轮次浮轨、按住看内容、按住后连续滑动预览、扫码访问、门禁与设备管理、设置里的开关都正常。
- 已经在用 `0.7.4` 的话不升也行，功能完全一样；升级只是让版本声明跟 DSH 对上。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。

<h3 id="en-v0.7.5">🔌 v0.7.5: keeps up with DSH 0.2.1-rc.2</h3>
