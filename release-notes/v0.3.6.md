<h3 id="cn-v0.3.6">🖥 局域网设备也能添加工作区</h3>

兼容 DeepSeek Harness `0.1.7-rc.2`。

- 手机或另一台电脑现在可以添加工作区：远程改用页面内的目录浏览器，选中后仍由 DSH 官方流程登记，插件只读目录。
- 修掉让远程管理台永远解锁不了的代理缺陷（只中转插件自己的 cookie，DSH 自身的会话 cookie 依旧不外泄）。
- 设置页补上缺失的「远程设备管理权限」控件；「已保存」改为右上角提示，不再把整页控件推下去。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。

<h3 id="en-v0.3.6">🖥 Add a workspace from another device on your LAN</h3>

Compatible with DeepSeek Harness `0.1.7-rc.2`.

- A phone or another computer can now add a workspace: remote devices get an in-page directory browser, and the chosen path is still registered by DSH's own flow. The plugin only reads directories.
- Fixes a proxy defect that made remote console unlock impossible (only the plugin's own cookie is relayed; DSH's session cookie never leaks).
- Adds the missing remote-device permission controls, and moves the "saved" toast to the corner so it stops pushing the page down.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Restart dsh once.
