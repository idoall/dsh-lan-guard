dsh-lan-guard `0.3.6` · 已验证 DeepSeek Harness `0.1.7-rc.2`

<h3 id="cn-v0.3.6">✨ 新增</h3>

- 局域网设备（手机或另一台电脑）现在可以添加工作区：本机照旧弹系统文件夹对话框，远程设备改用页面内目录浏览器（面包屑、快捷入口、目录列表），选中后仍由 DSH 官方流程登记，插件只读目录、不改任何文件。
- 远程设备可在目录浏览器里直接解锁管理台，不必再去设置页找解锁卡片。

### 🐛 修复

- 修掉一个让远程管理台**永远无法解锁**的代理缺陷：代理双向丢弃了插件自己的管理会话 cookie，导致「密码解锁」对远程设备形同虚设（表现为远程设置页解不开、添加工作区里是空的）。现在只中转插件自己的这一个 cookie，**DSH 自身的会话 cookie 依旧绝不外泄**。
- 设置页补上一直缺失的「远程设备管理权限」与「管理操作需要先解锁」控件（此前只能手改配置文件，而它正是远程目录浏览能否工作的开关）。
- 目录弹层的面包屑与快捷入口两行不再被压扁重叠。
- 状态提示的配色按深浅色实测重做：文字对比度从 3.6:1 / 4.4:1 提升到 16:1 / 9.8:1；危险提示此前用了 5% 透明的悬停色当背景，现在改为不透明。

### 🎨 优化

- 「已保存」从页面顶部横幅改为右上角提示：不再把整页控件推下去，带图标、关闭按钮与倒计时条。

### 升级

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

然后重启一次 DSH —— 宿主与客户端 bundle 都变了，刷新页面不够。

<h3 id="en-v0.3.6">✨ New Features</h3>

- LAN devices (a phone or another computer) can now add a workspace: the local browser still gets the OS folder dialog, while a remote device gets an in-page directory browser (breadcrumbs, shortcuts, a directory list). The chosen path is still registered by DSH's own flow — the plugin only reads directories and changes no files.
- A remote device can unlock the console right inside the directory browser, with no trip to the settings page.

### 🐛 Bug Fixes

- Fixed a proxy defect that left the remote console **permanently locked**: the proxy dropped the plugin's own admin session cookie in both directions, which made "password unlock" meaningless for a remote device (the settings page stayed locked and the workspace picker came up empty). Exactly that one cookie is now relayed — **DSH's own session cookie still never reaches a visitor**.
- The settings page now has the "remote management rights" and "management needs an unlock" controls that were missing entirely (until now they could only be changed by editing the config file — and they decide whether remote directory browsing works at all).
- The picker's breadcrumb and shortcut rows are no longer crushed into each other.
- Status colours were reworked against measured light/dark contrast: text goes from 3.6:1 / 4.4:1 to 16:1 / 9.8:1, and the danger surface no longer uses a 5%-alpha hover tint as its background.

### 🎨 Improvements

- The "saved" confirmation moved from a page-top banner to a top-right notification: it no longer pushes the page down, and it has an icon, a close button and a countdown bar.

### Upgrade

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Then restart DSH once — both the host and the client bundle changed, so a page refresh is not enough.
