<h3 id="cn-v0.1.0">🎉 首个版本：把 DSH 安全地开放给手机</h3>

兼容 DeepSeek Harness `0.1.7-rc.1`。

- 带门禁的反向代理，HTTP 与 WebSocket 全量转发。
- 默认自签 HTTPS；访问密码 + 管理密码 + 免密链接；设备配对、命名与逐个吊销。
- 本机直连免锁，远程默认只读；设置页挂在官方设置页里（扫码访问、安全认证、已授权设备、连接与证书）。
- 默认端口 3081，被占用会自动顺延。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。

<h3 id="en-v0.1.0">🎉 First release: DSH on your phone, safely</h3>

Compatible with DeepSeek Harness `0.1.7-rc.1`.

- A gated reverse proxy forwarding HTTP and WebSocket.
- Self-signed HTTPS by default; access password plus admin password, passwordless links, and device pairing with per-device revocation.
- Loopback stays unlocked; remote devices are read-only by default. Settings live inside DSH's own settings pages.
- Default port 3081, stepping to the next free port if taken.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Restart dsh once.
