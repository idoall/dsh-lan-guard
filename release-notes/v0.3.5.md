<h3 id="cn-v0.3.5">🔌 连接层更清楚，也不会再把自己锁在外面</h3>

兼容 DeepSeek Harness `0.1.7-rc.2`。

- 把地址写成 http:// 时，会自动跳到 https 并在日志里留下记录，不再是空白页。
- 删除设备记录后，这台浏览器可以用密码或新链接重新进入；吊销和拉黑仍然拒绝。
- 移除设备的提示文案跟着改准。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。

<h3 id="en-v0.3.5">🔌 Clearer connection handling, and no more locking yourself out</h3>

Compatible with DeepSeek Harness `0.1.7-rc.2`.

- Opening the address over http:// now redirects to https and leaves a log line instead of a blank page.
- After a device record is deleted, that browser can get back in with the password or a new link; revoked and blocked devices are still refused.
- The device-removal wording now matches what actually happens.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Restart dsh once.
