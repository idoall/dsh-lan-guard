<h3 id="cn-v0.7.2">🔌 v0.7.2：跟上 DSH 0.2.1-alpha.3</h3>

兼容 DeepSeek Harness `0.2.1-alpha.3`。

- 声明支持 DSH `0.2.1-alpha.3`：插件代码一行没动。
- 在 `0.2.1-alpha.3` 上确认过：手机端轮次浮轨、按住看内容、连续滑动预览、扫码访问、门禁与设备管理、设置里的开关都正常。
- 已经在用 `0.7.1` 的话不升也行，功能完全一样；升级只是让兼容声明跟 DSH 对上。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。
