<h3 id="cn-v0.3.4">⚙️ 局域网设备也能用官方设置页</h3>

兼容 DeepSeek Harness `0.1.7-rc.2`。

- 手机上打开「设置 → 模型」不再报「此浏览器不可用」。
- 新增开关「局域网设备可用官方设置页」，默认开启，刷新页面即生效。
- 这只是解锁界面，不新增权限；关掉就恢复 DSH 原生行为。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。

<h3 id="en-v0.3.4">⚙️ LAN devices can use DSH's own settings pages</h3>

Compatible with DeepSeek Harness `0.1.7-rc.2`.

- "Settings → Models" no longer reports that settings are unavailable on a phone.
- New switch, on by default; reload the page to apply.
- This unlocks the UI only and grants no new permissions; turning it off restores DSH's stock behaviour.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Restart dsh once.
