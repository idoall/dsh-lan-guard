<h3 id="cn-v0.7.1">📖 v0.7.1：文档版，只改文字</h3>

兼容 DeepSeek Harness `0.2.1-alpha.1`。

- 功能和 0.7.0 完全一样，只是把 README 和历次发布说明改成了人话：去掉实现细节，只讲这版干了什么。
- 重新发一版，是因为 npm 页面展示的是发布包里的 README——只有发新版才能把新文档送上去。

<h3>升级</h3>

