<h3 id="cn-v0.7.8">🔌 v0.7.8：跟住 DSH 0.2.2-alpha.2 的多语言界面</h3>

兼容 DeepSeek Harness `0.2.2-alpha.2`；支持范围 `>=0.1.7-rc.1 <0.3.0` 不变。
这次上游是真改动：界面语言从中文/英文扩到 8 种，手机轮次浮轨因此有一处必须跟着改。

- DSH 0.2.2 把界面文案全面本地化，官方「轮次导航」那根浮轨的 `aria-label` 也有 8 种语言。本插件原来只认中文和英文两种标签，**切到日、西、法、德、俄、葡任意一种，手机上的浮轨就贴不回正确位置，按住预览也用不了**。这一版把 8 种标签全部收进来，并加了一条结构化兜底：将来 DSH 再加语言，浮轨按「只有它的刻度带 `data-index`」被认出来，不用等插件发版。
- 其余是兼容声明与文档：`dsh.compatibility.dshReleases` 增加 `0.2.2-alpha.2`，开发依赖同步到该版本；宿主与客户端接口逐包比对过，本插件用到的那几个签名没有破坏性变化。
- 核对过：类型检查通过；23 个测试文件、388 项用例全绿（新增 2 项，专门盯 8 种语言标签与未知语言兜底）；新版界面在真实 Chrome 里用中文、日文、未知语言三种标签各跑了一遍，浮轨的宽度/贴边/触摸行为都按预期生效；局域网入口、客户端补丁注入、`/config` 与 `/devices` 在运行 0.2.2-alpha.2 的实例上正常。
- 上游 0.2.2 新增的 per-Peer 注入、`resource` 路由与 `readResource` 评估过但**没有采用**：`resource` 路由拿不到客户端地址，而门禁与「仅本机」策略要靠它，换成它会削弱安全边界。

⚠️ 两点说明：手机实机验收（触摸、锁屏、语音）这版还没做；插件自己的设置页仍然只有中文，DSH 已经能切 8 种语言，这块翻译留到下一版，不在本版硬塞。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@0.7.8
```
重启 DSH 一次。

已经在用 `0.7.7` 且界面用中文或英文的话，功能上没有区别；用其他语言的话，这版修好了手机浮轨。

<h3 id="en-v0.7.8">🔌 v0.7.8: keeps up with DSH 0.2.2-alpha.2's multi-language UI</h3>

Compatible with DeepSeek Harness `0.2.2-alpha.2`; the supported range `>=0.1.7-rc.1 <0.3.0` is unchanged.
This upstream release is a real change: the UI language catalog grew from Chinese/English to eight locales, which forced one fix in the phone turn rail.

- DSH 0.2.2 localises UI copy throughout, including the official turn navigator's `aria-label`. The plugin only matched the Chinese and English labels, so **picking Japanese, Spanish, French, German, Russian or Portuguese left the phone rail without its gutter placement and without the hold-to-preview gesture**. This release matches all eight labels and adds a structural fallback: if DSH adds a language later, the rail is recognised by being the only `<nav>` whose marks carry `data-index`, so it does not need another release here.
- The rest is declarations and docs: `dsh.compatibility.dshReleases` gains `0.2.2-alpha.2` and the dev dependencies move to that release; every host and client package was compared, and none of the signatures this plugin uses changed in a breaking way.
- Checked: type checking passes; 23 test files and 388 cases are green (two new ones cover the eight labels and the unknown-language fallback); the rail's width, edge placement and touch behaviour were exercised in real Chrome for a Chinese, a Japanese and an unknown label; the LAN entry, client patch injection, `/config` and `/devices` all work on a running `0.2.2-alpha.2` instance.
- The per-Peer injection, `resource` routes and `readResource` that 0.2.2 introduces were evaluated and **not adopted**: a resource route exposes no client socket, and the gate plus the "local only" policy depend on it, so switching would weaken the security boundary.

⚠️ Two notes: on-device acceptance (touch, lock screen, dictation) is not done for this release; and the plugin's own settings panel is still Chinese-only while DSH now offers eight languages — that translation is left for a later release rather than rushed in here.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@0.7.8
```
Restart DSH once.

Already on `0.7.7` with a Chinese or English UI? Behaviour is the same. On any other language, this release fixes the phone rail.
