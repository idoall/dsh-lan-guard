<h3 id="cn-v0.3.2">📦 装完即用</h3>

兼容 DeepSeek Harness `0.1.7-rc.2`。

- 安装后只需重启一次 DSH，不用手写配置：数据目录有默认位置。
- 默认对外监听（门禁与自签 HTTPS 仍然默认开启，没设访问密码时拒绝所有设备）。
- 设置页换成液体玻璃材质、尺寸对齐官方；新增「监听范围」开关。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。

<h3 id="en-v0.3.2">📦 Works right after install</h3>

Compatible with DeepSeek Harness `0.1.7-rc.2`.

- Restart DSH once and it runs — no hand-written config: the data directory has a default.
- Listens on the LAN by default (the gate and self-signed HTTPS stay on, and with no access password every device is refused).
- A liquid-glass settings page that matches DSH's sizing, plus a "listen scope" switch.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Restart dsh once.
