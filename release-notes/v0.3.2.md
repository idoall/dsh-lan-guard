<h3 id="cn-v0.3.2">中文</h3>

### ⚠️ 破坏性默认值变更：默认对外监听

`listenHost` 的默认值由 `127.0.0.1` 改为 **`0.0.0.0`**。

原因很实际：本插件的用途就是把界面开放到局域网，而用户装完后**只会重启一次 DSH**。旧默认值要求"改配置 → 再重启一次"才能用，体验不可接受。

**这不是"关掉安全"**，默认值仍然成对成立：

- 门禁默认**开启**，且**未设置访问密码时拒绝所有设备**（登录页可见，但不放行、不泄露任何数据）；
- TLS 默认**自签 HTTPS**，不存在明文传输；非回环 + 关闭 TLS 依旧**拒绝启动**。

想只在本机使用，在 **设置 → 局域网访问 → 连接与证书** 里切到「仅本机」即可（改动需重启 DSH 生效）。

### 装完即用

- **`dataDir` 不再必填**：不写就用 `<当前 profile>/data/dsh-lan-guard`（例如 `~/.dsh/profiles/web/data/dsh-lan-guard`），写了就优先用你的（支持 `~` 前缀）。显式配置仍可覆盖，但不再是使用前提。
- **修复安装后设置页显示 `settings request failed: 404`**：此前包内条目不带 config、而 `dataDir` 是必填项，插件因此拒绝启动，宿主半边一条路由都没注册；客户端半边独立注入，于是只显示一个裸 404。
- 顺带修掉 `~` 不展开的问题：此前 `dataDir: ~/x` 会在进程当前目录下建一个**字面量 `~` 目录**。

### 设置页

- **新增「监听范围」开关**：局域网（默认）/ 仅本机，两选一；端点只接受这两个值，具体网卡 IP 仍属 profile patch 的高级配置。`auth.enabled: false` 时拒绝写入非回环地址（否则下次重启起不来）。
- **新增 Liquid Glass 液体玻璃材质**：毛玻璃 + 跟随主题的折射光晕 + 镜面渐变描边 + 分层投影。材质全部由官方设计令牌经 `color-mix` 派生，浅色/深色自动适配；每个表面都保留纯色令牌回退。**二维码底板刻意保持不透明**（半透明会降低对比度、可能扫不出来）。
- **尺寸对齐 DSH 官方设置页**：控件 44px → **36px**、按钮字重 500 → **400**、圆角 → **12px**、卡片标题 16px → **14px**。触屏仍保留 44px 最小高度，手机点击目标不变。
- **修复提示条按钮折行**（原先显示成「去设置访 / 问密码」）：按钮固定整行，文本改为在自身内部换行。
- **访问地址与升级命令改为单行横向滚动**：不再硬折行占垂直空间（框高约 62px → 42px）；**复制仍复制全文**。

### 仓库整理

- README 中英双语重写（对齐社区插件的版式），新增 **5 张真实截图**与 `screenshots.json`；
- 移除 `docs/` 设计文档与 `AGENTS.md` 协作总纲，并清理全仓引用。

### 验证

- `pnpm test`（含类型检查）**241 项全绿**，`pnpm run build` 通过；
- 真实 DSH 浏览器实测：未设密码时局域网请求返回 **403** 且拿不到界面；设密码后未登录 **401**、登录并配对后 **200** 拿到官方 UI；
- 设置页尺寸、玻璃材质、按钮不折行、地址框滚动均以 `getComputedStyle` 与截图逐项确认。

### 升级

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

然后重启一次 DSH。升级不会自动安装或重启任何东西——命令由你执行。

<h3 id="en-v0.3.2">English</h3>

### ⚠️ Breaking default change: LAN-facing by default

`listenHost` now defaults to **`0.0.0.0`** instead of `127.0.0.1`.

The reason is practical: this plugin exists to expose the UI to your LAN, and an install involves **exactly one DSH restart**. The old default forced "edit config, restart again" before it was usable.

**This is not "security off"** — the defaults still hold together:

- the gate is **on** by default and **refuses every device until an access password is set** (the login page is visible, but nothing is let through and no data leaks);
- TLS defaults to **self-signed HTTPS**, so nothing travels in clear; a non-loopback bind with TLS off is still **refused at startup**.

To keep it local, switch to "this machine only" under **Settings → 局域网访问 → 连接与证书** (takes effect after a DSH restart).

### Install and go

- **`dataDir` is no longer required**: omit it and the plugin uses `<active profile>/data/dsh-lan-guard` (e.g. `~/.dsh/profiles/web/data/dsh-lan-guard`); set it and your value wins (a leading `~` is expanded). An explicit value still overrides, but is no longer a prerequisite.
- **Fixed `settings request failed: 404` right after install**: the bundled entry carried no config while `dataDir` was mandatory, so the plugin refused to start and registered no host routes; the client half is injected independently, so all you saw was a bare 404.
- Also fixed: a leading `~` was not expanded, so `dataDir: ~/x` created a **literal `~` directory** under the process CWD.

### Settings page

- **New listen-scope switch**: LAN (default) / this machine only. The endpoint accepts exactly those two values; a specific NIC IP remains an advanced profile-patch setting. Writing a non-loopback address is refused while `auth.enabled: false` (it would break the next restart).
- **New Liquid Glass material**: frosted blur, a theme-following refracted glow, a specular gradient rim and layered depth. Every value is derived from official design tokens through `color-mix`, so light and dark adapt automatically, and every surface keeps a solid token fallback. **The QR plate stays deliberately opaque** (translucency would hurt contrast and could break scanning).
- **Sizes aligned with DSH's own settings page**: controls 44px → **36px**, button weight 500 → **400**, radius → **12px**, card title 16px → **14px**. Touch keeps its 44px minimum, so phone tap targets do not shrink.
- **Fixed the notice button wrapping** (it read "去设置访 / 问密码"): the button now stays on one line and the text wraps inside itself.
- **The access URL and the upgrade command are single-line horizontally scrollable fields**: no more hard wrapping eating vertical space (box height ~62px → 42px), and **copy still copies the whole value**.

### Repository housekeeping

- Both READMEs rewritten (matching the community-plugin layout) with **5 real screenshots** and a `screenshots.json`;
- Removed the `docs/` design documents and the `AGENTS.md` collaboration charter, and cleaned every reference.

### Verification

- `pnpm test` (including type checking) — **241 passing**; `pnpm run build` passes;
- Measured in a real DSH in the browser: with no password set a LAN request returns **403** and never reaches the UI; after setting a password an unauthenticated request returns **401**, and logging in plus pairing returns **200** with the official UI;
- Settings sizing, the glass material, the non-wrapping button and the scrolling URL field were each confirmed with `getComputedStyle` and screenshots.

### Upgrade

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Then restart DSH once. The plugin never installs or restarts anything by itself — you run the command.
