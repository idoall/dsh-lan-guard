<h3 id="cn-v0.7.9">v0.7.9：适配 DSH 0.2.2-alpha.3，修复手机目录弹层</h3>

兼容 DeepSeek Harness `0.2.2-alpha.3`；支持范围 `>=0.1.7-rc.1 <0.3.0` 不变。

- **修复**：alpha.3 的手机侧栏改为带 transform 的抽屉，旧目录选择弹层会被限制在侧栏内。改用原生 modal dialog 顶层显示，仍由原来的官方 slot 和 React 管理，不移动到 body、不修改官方布局；加载与忙碌状态共用同一个 dialog，取消与卸载会清理，忙碌时 Escape 不打断操作。
- **核验**：真实 alpha.3 界面 + Chromium，390px 视口下旧版弹层只有 280px，修复后为 390px；1024px 视口下遮罩 1024px、卡片 560px；侧栏和首页入口均可打开，Escape/取消后关闭。测试通过浏览器路由仅替换本插件的客户端响应，其余客户端资源继续来自现有宿主；未改 profile、未安装新包。测试使用本地代理与测试域名，未覆盖完整 LAN/WebSocket 或手机实机触摸、锁屏、语音，也未执行工作区登记或管理解锁。
- Host 的 webserver/connection/scope 与 alpha.2 对应构建及类型一致；Cordis 内部生命周期有重构，但本插件使用的公开接口保留。开发依赖与锁文件同步到 alpha.3、Cordis `4.0.6-alpha.2`、Schemastery `3.18.6-alpha.2`。
- 类型检查、23 文件 / 390 项回归用例、构建及版本/打包检查通过。新增两项目录弹层结构回归。
- 中英文 README 同步徽章、插件版本、DSH 版本、兼容清单和 tag；纠正「拉黑可跨浏览器识别物理设备」、已移除的回到底部按钮及浮轨尺寸/手势的过时说明。门禁不变，拉黑针对已记录身份，共享密码可在新浏览器重新配对。
- 2026-11-03 核对 npm：DSH `alpha` 为 `0.2.2-alpha.3`，`latest` / `next` 为 `0.2.1-rc.5`；本次不声明 rc.5 已验证。只修改本插件工作区。

```sh
dsh plugin --profile web add dsh-lan-guard@0.7.9
```

安装后重启 DSH 一次。运行实例本次仍保留 `0.7.8`，发布不等于自动安装。

<h3 id="en-v0.7.9">v0.7.9: DSH 0.2.2-alpha.3 and a mobile directory-dialog fix</h3>

Compatible with DeepSeek Harness `0.2.2-alpha.3`; the supported range `>=0.1.7-rc.1 <0.3.0` is unchanged.

- **Fix:** alpha.3 turns the mobile sidebar into a transformed drawer, trapping the old fixed-position directory picker inside it. A native modal dialog now uses the browser top layer while remaining owned by the original slot and React. No body portal or official-layout edits. Loading and busy states share the dialog; cancellation/unmount cleans up, and Escape does not interrupt a busy adoption.
- **Checked:** on the real alpha.3 UI in Chromium, the old overlay measured 280px in a 390px viewport; the fix measures 390px. At 1024px, the overlay is 1024px and the card is 560px. Sidebar and hero entries open, and Escape/cancel closes the dialog. Browser routing replaced only this plugin's client response with the local build; other client resources came from the existing host. No profile change or package installation. This local proxy/test-domain check does not cover full LAN/WebSocket or on-device touch, screen locking and dictation; no workspace registration or management unlock was performed.
- Host webserver/connection/scope builds and types match alpha.2. Cordis changes internal lifecycle bookkeeping but retains the public interfaces used here. Development dependencies and the lockfile move to alpha.3, Cordis `4.0.6-alpha.2` and Schemastery `3.18.6-alpha.2`.
- Type checks, 23 test files / 390 cases, build and version/package checks pass; two picker-structure regressions were added.
- Both READMEs update badges, plugin/DSH versions, verified lists and tag commands, and correct stale device-blocking, back-to-bottom and turn-rail descriptions. Authentication is unchanged: blocking targets a recorded identity, not a physical device across browsers; the shared password can pair a fresh browser.
- Registry channels checked on 2026-11-03: DSH `alpha` = `0.2.2-alpha.3`, `latest` / `next` = `0.2.1-rc.5`. rc.5 is not claimed as verified. Changes are confined to this plugin workspace.

```sh
dsh plugin --profile web add dsh-lan-guard@0.7.9
```

Restart DSH after installation. The running instance remains on `0.7.8`; publishing does not install the package automatically.
