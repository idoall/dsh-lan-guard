<h3 id="cn-v0.3.0">✅ 新设备要管理员批准，分享的链接不再白屏</h3>

兼容 DeepSeek Harness `0.1.7-rc.1`。

- 新增「新设备需要批准」开关（默认关闭）：打开后新设备要管理员点一下批准才能用。
- 「吊销并拉黑」是永久的，只有管理员能解除；已有设备不受影响。
- 修掉分享出去的链接打开后页面空白的问题：现在会先看到配对页，命名之后资源才放行。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。

<h3 id="en-v0.3.0">✅ New devices can require approval, and shared links no longer go blank</h3>

Compatible with DeepSeek Harness `0.1.7-rc.1`.

- New switch (off by default): with approval on, a new device waits for an admin to approve it.
- "Revoke and block" is permanent and only an admin can undo it; existing devices are untouched.
- Fixes blank pages from shared links: the pairing page now comes first and resources load after naming.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Restart dsh once.
