<h3 id="cn-v0.4.0">🔌 手机连接不再轻易掉线</h3>

兼容 DeepSeek Harness `0.1.7-rc.2`。

- 代理替页面回 DSH 的心跳，手机切到后台再回来不会掉线。
- 页面补上断线看门狗，真的断了会自动恢复。
- 「连接与证书」新增连接体检，能看到当前连接状态。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。

---

<h3 id="en-v0.4.0">🔌 Phone connections stop dropping</h3>

Compatible with DeepSeek Harness `0.1.7-rc.2`.

- The proxy answers DSH's heartbeats for the page, so switching apps and coming back no longer drops the connection.
- A watchdog on the page recovers if it really does disconnect.
- A connection check-up in Settings shows the current state.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Restart dsh once.
