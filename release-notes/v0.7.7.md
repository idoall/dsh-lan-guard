<h3 id="cn-v0.7.7">🔌 v0.7.7：跟上 DSH 0.2.1-rc.4</h3>

兼容 DeepSeek Harness `0.2.1-rc.4`；支持范围 `>=0.1.7-rc.1 <0.3.0` 不变。
这一版**只动声明和文档，插件代码一行没改**。

- 上游 rc.4 是一次「只改版本号」的发布：本插件用到的宿主与客户端包（webserver、connection、client-ui-renderer / layout / settings / settings-general、scope）除版本字符串外逐字节一致，DSH CLI 的 `lib` 也完全没变。所以 rc.4 对插件没有接口或行为变更。
- 用 rc.4 的类型重新构建，`lib` 四个文件与已发布的 `0.7.6` 包内文件 SHA-256 完全相同——构建可复现，改动确实只在声明层。
- 核对过：类型检查通过；23 个测试文件、386 项用例全绿；`--dump-config` 里插件与你的已存配置正常合成、没有被拒载；局域网入口正常打开，客户端补丁照旧注入，设置页的 `/config` 与 `/devices` 都返回真实数据。
- 中英文 README 已同步：徽章、已验证版本、当前版本句、兼容表、11 个已验证版本清单、发版 tag 示例。npm 包内容与仓库一致。

⚠️ rc.4 上的手机/浏览器交互验收（触摸、锁屏、语音）还没做，本版不把 rc.3 的实测结论冒充成 rc.4 的。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@0.7.7
```
重启 DSH 一次。

已经在用 `0.7.6` 的话，升级只是让版本声明跟 DSH 对上，功能完全一样。

<h3 id="en-v0.7.7">🔌 v0.7.7: keeps up with DSH 0.2.1-rc.4</h3>

Compatible with DeepSeek Harness `0.2.1-rc.4`; the supported range `>=0.1.7-rc.1 <0.3.0` is unchanged.
This release **only touches declarations and docs — no plugin code changed.**

- Upstream rc.4 is a version-string-only release: the host and client packages this plugin uses (webserver, connection, client-ui-renderer / layout / settings / settings-general, scope) are byte-identical to rc.3 apart from the version field, and the DSH CLI `lib` is unchanged too. So rc.4 brings no interface or behavioural change for the plugin.
- Rebuilding against rc.4 types produces four `lib` files whose SHA-256 matches the published `0.7.6` tarball exactly — the build is reproducible, and the change really is declaration-only.
- Checked: type checking passes; 23 test files and 386 cases are green; `--dump-config` composes the plugin together with your stored settings and nothing is refused; the LAN entry opens as before, the client patch is still injected, and the settings page's `/config` and `/devices` return real data.
- Both READMEs were reconciled: badge, verified release, current-version sentence, compatibility table, the full 11-release list and the release-tag example. What npm ships matches the repository.

⚠️ Phone/browser interaction acceptance on rc.4 (touch, lock screen, dictation) is not done; this release does not pass rc.3's end-to-end results off as rc.4 measurements.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@0.7.7
```
Restart DSH once.

Already on `0.7.6`? Upgrading only lines the version statements up with DSH — behaviour is identical.
