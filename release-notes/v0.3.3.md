<h3 id="cn-v0.3.3">🚪 门禁体验修复</h3>

兼容 DeepSeek Harness `0.1.7-rc.2`。

- 失效的链接页现在可以输入密码登录，不再是灰色表单。
- 设备被移除后的提示改成真正可操作的做法。
- 首次访问会提前说明要过哪两道关。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。
