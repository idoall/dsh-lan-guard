<h3 id="cn-v0.2.0">🔄 新增升级检测，移除右下角常驻提示</h3>

兼容 DeepSeek Harness `0.1.7-rc.1`。

- 设置页会显示当前版本和 npm 上的最新版本，并给出可复制的升级命令；只提示，不自动安装、不自动重启。
- 移除了右下角常驻的状态胶囊——它会把免密链接一直显示在屏幕上，截屏会一起被拍进去。
- 链接本身没变，需要时在设置页「扫码访问」里看。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。

---

<h3 id="en-v0.2.0">🔄 Update check, and the always-on corner badge is gone</h3>

Compatible with DeepSeek Harness `0.1.7-rc.1`.

- Settings now shows your version next to the latest on npm, with a copyable upgrade command. It only reports — it never installs or restarts anything.
- The always-on corner badge is removed: it kept your passwordless link on screen, so screenshots and screen shares leaked it.
- The link itself is unchanged; open the "scan to visit" tab when you need it.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Restart dsh once.
