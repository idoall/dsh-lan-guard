<h3 id="cn-v0.4.3">📱 换个修法：修高度，而不是打补丁</h3>

兼容 DeepSeek Harness `0.2.0-rc.1`。

- 不再给内容层打 overflow 补丁，改成让手机端的高度链正常，页面自己就能滚。
- 撤掉了自建的「回到底部」按钮，交回官方。
- 兼容声明放宽，避免 DSH 正式版发布当天插件被静默丢弃。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。

<h3 id="en-v0.4.3">📱 A different fix: repair the height chain instead of patching layers</h3>

Compatible with DeepSeek Harness `0.2.0-rc.1`.

- Instead of patching the content layer with overflow, the mobile height chain is repaired so the page scrolls on its own.
- The self-made back-to-bottom button is gone; DSH's own button is back in charge.
- The compatibility declaration was widened so the plugin is not silently dropped on the day DSH ships its stable release.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Restart dsh once.
