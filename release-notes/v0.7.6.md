<h3 id="cn-v0.7.6">🔌 v0.7.6：跟上 DSH 0.2.1-rc.3</h3>

本版同步新版 DSH 的兼容声明，插件运行时功能不变。
兼容 DeepSeek Harness `0.2.1-rc.3`；支持范围 `>=0.1.7-rc.1 <0.3.0`。

⚠️ 调整
- 新版接口、类型与自动回归已核对；手机/浏览器交互验收待完成，不宣称已经实测通过。
- 中英文 README 已全文重新校对，当前插件、DSH 版本及发版示例同步更新。
- npm 包内容与仓库同步纳入发布校验；升级不改变现有门禁、证书或设备配置。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@0.7.6
```
重启 DSH 一次。
