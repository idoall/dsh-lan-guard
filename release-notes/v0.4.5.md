<h3 id="cn-v0.4.5">📱 长会话不再只显示一小段</h3>

兼容 DeepSeek Harness `0.2.0-rc.1`。

- 长会话的正文加载得比较晚，旧逻辑以为已经正常就收工了，结果手机上只能看到一小段、拖不到底。
- 现在会继续等正文进来，确认真的能滚动之后才收工；修不好就整体撤回，页面保持官方原样。
- 只影响手机上的长会话，桌面不受影响。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。

<h3 id="en-v0.4.5">📱 Long conversations no longer show just a small slice</h3>

Compatible with DeepSeek Harness `0.2.0-rc.1`.

- Long transcripts load late; the old logic assumed everything was fine and stopped, so a phone showed only a short slice that would not scroll.
- It now waits for the transcript and only stops once scrolling really works; if it cannot, it backs out and leaves the page as DSH shipped it.
- Phone-only, and only for long sessions.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Restart dsh once.
