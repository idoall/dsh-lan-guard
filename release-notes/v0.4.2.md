<h3 id="cn-v0.4.2">📱 找回官方的「回到底部」按钮</h3>

兼容 DeepSeek Harness `0.1.7-rc.2`。

- 之前的窄屏矫正让官方按钮误以为一直在底部，于是按钮不再出现；现在它回来了。
- 修掉矫正补丁和全屏遮罩打架、侧边栏被灰雾盖住的问题。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。

<h3 id="en-v0.4.2">📱 Brings back DSH's own back-to-bottom button</h3>

Compatible with DeepSeek Harness `0.1.7-rc.2`.

- The earlier narrow-screen correction made DSH think it was always at the bottom, so its button disappeared; it is back now.
- Also fixes the greyed-out sidebar caused by the correction fighting the full-screen overlay.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Restart dsh once.
