<h3 id="cn-v0.5.0">🔌 支持新版 DSH，并把手机端的轮次浮轨放出来</h3>

兼容 DeepSeek Harness `0.2.1-alpha.1`。

- 兼容 DeepSeek Harness 0.2.1-alpha.1（只更新声明，运行代码没变）。
- 新增手机端轮次浮轨（默认关闭）：手机上也能用右侧那根轮次条，点一下就跳到那一轮，没加载过的会先翻历史。
- 用的还是 DSH 官方组件，插件不重写导航；万一官方改了隐藏规则，插件会自动撤回，页面回到原样。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。

---

<h3 id="en-v0.5.0">🔌 Supports the new DSH and brings the turn rail to phones</h3>

Compatible with DeepSeek Harness `0.2.1-alpha.1`.

- Compatible with DeepSeek Harness 0.2.1-alpha.1 (declaration only; runtime code unchanged).
- New phone turn rail (off by default): the rail on the right works on a phone — tap a tick to jump, and earlier turns are paged in first.
- It is still DSH's own component, not a rewrite; if upstream changes how the rail is hidden, the plugin backs out and the page returns to stock.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Restart dsh once.
