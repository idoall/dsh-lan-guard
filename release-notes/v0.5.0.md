<h3 id="cn-v0.5.0">🔌 兼容 DeepSeek Harness 0.2.1-alpha.1</h3>

- 适配仅声明、零代码：本插件依赖的宿主接口全部原位；类型检查与 368 个用例通过。
- devDependency 连带升级 `@deepseek-ai/cordis` `4.0.5-alpha.1`、`@deepseek-ai/schemastery` `3.18.5-alpha.1`（新宿主包的 peer 要求），插件使用者无需操作。

### ✨ 新增功能

- 手机端也能看到会话右侧那根轮次浮轨（`mobileTurnRail`，**默认关闭**）：DSH 在手机上照样渲染它，只是被自己的窄屏样式藏了起来，本插件把它放出来并挪进对话区右侧留白，不再压住正文。
- 浮轨原样复用官方组件：点刻度跳轮次、未加载的先翻历史、当前轮次跟随、悬停预览；插件不重写导航、不新建滚动容器、不加按钮。
- 上游若改动隐藏规则，脚本自检失败会在约 3 秒内摘下注入样式、页面回到官方原样；`?lgdiag=1` 底部新增一屏轮次导航诊断。

### ⚠️ 其他变更

- 触控精度与 PC 相同：每格 24×10px，格间距由官方脚本锁定为 10px，不适合随手点得准。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。开关在 **设置 → 局域网访问 → 连接与证书 → 手机端轮次导航**，打开后刷新页面生效。

<h3 id="en-v0.5.0">🔌 Compatible with DeepSeek Harness 0.2.1-alpha.1</h3>

- Declaration-only adaptation, zero code: every host interface this plugin uses is unchanged; the type check and all 368 specs pass.
- devDependencies raised in step with it: `@deepseek-ai/cordis` to `4.0.5-alpha.1` and `@deepseek-ai/schemastery` to `3.18.5-alpha.1` (the new host packages peer-require them). Nothing to do on the user side.

### ✨ New

- The session turn rail (the floating marks on the right of a chat) is now available on phones too (`mobileTurnRail`, **off by default**): DSH already renders it there and only hides it with its own narrow-screen rule, so the plugin un-hides it and moves it into the chat frame's right gutter instead of over the text.
- It reuses the official component as-is: tap a mark to jump to that turn, unloaded turns page the history in first, the active turn follows, hover previews keep working. No reimplemented navigation, no new scroll container, no added buttons.
- If upstream ever changes its hiding rule, the script's self-check removes the injected stylesheet within about 3 seconds and the page is stock again. `?lgdiag=1` adds a turn-rail diagnostic panel at the bottom.

### ⚠️ Chores

- Touch precision is the same as on the desktop: each mark is 24×10px and the pitch is locked to 10px by DSH's own script, so it is not meant for casual thumb taps.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Restart dsh once. The switch is under **Settings → 局域网访问 → 连接与证书 → 手机端轮次导航** and applies on the next page load.
