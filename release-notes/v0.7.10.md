<h3 id="cn-v0.7.10">v0.7.10：兼容 DSH 0.2.2-rc.1</h3>

兼容 DeepSeek Harness `0.2.2-rc.1`；支持范围 `>=0.1.7-rc.1 <0.3.0` 不变。

- 更新已验证兼容清单及开发依赖：DSH 宿主包与 scope → `0.2.2-rc.1`，Cordis → `4.1.0`，Schemastery → `3.19.0`。现有 peer 范围已覆盖这些版本，不需要额外放宽或版本豁免。
- 对照 alpha.3 基线，webserver、connection、scope、Cordis 和 Schemastery 的非 map 构建与类型文件逐字节一致；核心 `register` / `tapIndex` / `requestRejection` / `authenticatedUrl` 契约保持不变。
- **运行时源码不变**。换用新版依赖后构建的四个 lib 文件与已发布 `0.7.9` 包逐字节一致；保留上一版的原生目录弹层修复。
- 使用 rc.1 类型检查，23 个测试文件 / 390 项自动回归通过；现有 rc.1 实例的代理首页、页面补丁注入及管理配置/设备接口只读检查正常。
- 两版 README 的徽章、当前插件与 DSH 版本、兼容表、14 个历史验证版本清单及 tag 示例同步；发布说明与 npm 实际包在发布前后分别核验。
- 2026-11-04 核对 npm 渠道：`next` = `0.2.2-rc.1`，`alpha` = `0.2.2-alpha.3`，`latest` = `0.2.1-rc.5`。本次不把 `0.2.1-rc.5` 列为已验证。

**验证边界**：未重做 rc.1 浏览器交互、完整 LAN/WebSocket 或手机触摸/锁屏/语音验收；上一版 alpha.3 的浏览器测量不等同于本次实测。只修改本插件工作区，不更改 profile、其他插件或自动安装/重启。

```sh
dsh plugin --profile web add dsh-lan-guard@0.7.10
```

安装后重启 DSH 一次。

<h3 id="en-v0.7.10">v0.7.10: compatibility with DSH 0.2.2-rc.1</h3>

Compatible with DeepSeek Harness `0.2.2-rc.1`; the supported range `>=0.1.7-rc.1 <0.3.0` is unchanged.

- Update the verified compatibility list and development dependencies: DSH host packages and scope → `0.2.2-rc.1`, Cordis → `4.1.0`, Schemastery → `3.19.0`. Existing peer ranges already include these versions; no range widening or version exemption is needed.
- Compared with the alpha.3 baseline, non-map builds and type files for webserver, connection, scope, Cordis and Schemastery are byte-identical. The core `register` / `tapIndex` / `requestRejection` / `authenticatedUrl` contracts are unchanged.
- **No runtime source changes.** All four lib artifacts built against the new dependencies are byte-identical to the published `0.7.9` package, retaining its native directory-dialog fix.
- rc.1 type checks and 23 test files / 390 automated cases pass. Read-only checks on the running rc.1 instance confirm the proxy index, page patch injection and management config/device endpoints.
- Both READMEs update their badges, plugin/DSH versions, compatibility table, 14 historical verified releases and tag examples. Release notes and actual npm package contents are checked before/after publication.
- Registry channels checked on 2026-11-04: `next` = `0.2.2-rc.1`, `alpha` = `0.2.2-alpha.3`, `latest` = `0.2.1-rc.5`. `0.2.1-rc.5` is not claimed as verified.

**Verification limits:** rc.1 browser interactions, full LAN/WebSocket and on-device touch/screen-lock/dictation acceptance were not repeated. The previous alpha.3 browser measurements are not rc.1 evidence. Changes are confined to this plugin workspace; no profile or other-plugin changes, automatic installation or restart.

```sh
dsh plugin --profile web add dsh-lan-guard@0.7.10
```

Restart DSH after installation.
