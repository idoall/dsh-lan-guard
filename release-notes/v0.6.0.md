<h3 id="cn-v0.6.0">📱 手机端的轮次提示，改成了「按住看内容」</h3>

- 官方那套提示是**悬停**交互，触屏永远触发不了（轻点直接跳转）——所以手机上「看得见刻度、看不到内容」。现在**按住刻度约 0.3 秒**会弹出卡片，显示这一轮的用户提问与回复摘要。
- 卡片带 **◀ ▶** 逐轮微调和「跳到第 N 轮」一键跳转，不必再去瞄准 10px 的刻度；轻点跳转、拖动滚动都与原来一致。
- 轨道往内挪了一点、刻度加粗到 3px（仍是官方配色，明暗自动跟随）；它左边紧贴正文列，无法再往中间挪，所以「点得准」交给卡片。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次；`mobileTurnRail` 在 **设置 → 局域网访问 → 连接与证书 → 手机端轮次导航**，打开后刷新页面生效。

<h3 id="en-v0.6.0">📱 The phone turn rail now shows a turn’s content on hold</h3>

- DSH's preview is a **hover** affordance, which a touch screen can never trigger (a tap navigates immediately) — that is why the marks were visible but showed nothing. **Holding a mark for ~0.3s** now opens a card with that turn's prompt and an excerpt of the reply.
- The card carries **◀ ▶** steppers and a one-tap jump, so the 10px tick is never the target; tap-to-jump and drag-to-scroll behave exactly as before.
- The rail moved slightly inwards and its ticks grew to 3px (official tokens, so light/dark follow). It sits flush against the message column and cannot move further in, so precision comes from the card.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Restart dsh once; `mobileTurnRail` is under **Settings → 局域网访问 → 连接与证书 → 手机端轮次导航** and applies on the next page load.
