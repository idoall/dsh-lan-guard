<h3 id="cn-v0.4.4">📱 修好 iOS 上「打开会话不在最新、手指拖不动」</h3>

兼容 DeepSeek Harness `0.2.0-rc.1`。

- 会话内部有一层把内容裁掉了，导致打开会话停在中间、手指几乎拖不动。
- 现在让那一层放开高度，滚动恢复正常；输入框仍然吸底，官方「回到底部」按钮回到原位。
- 只动那一层，桌面不受影响。

<h3>升级</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

重启 dsh 一次。

<h3 id="en-v0.4.4">📱 Fixes iOS sessions that opened away from the newest message and barely scrolled</h3>

Compatible with DeepSeek Harness `0.2.0-rc.1`.

- A clipped inner layer cut the conversation short, so a session opened mid-way and the finger could hardly drag.
- That layer now releases its height and scrolling works again; the composer stays pinned and DSH's own back-to-bottom button returns.
- Only that layer is touched; desktop is unaffected.

<h3>Upgrade</h3>

```sh
dsh plugin --profile web add dsh-lan-guard@latest
```

Restart dsh once.
